# The Artisan Kiln

Адаптивная форма заказа керамической плитки для тестового задания Tile.Expert.

**Стек:** Next.js, React, TypeScript, Tailwind CSS и Redux Toolkit.

## Возможности

- Корзина с изменением количества, добавлением коллекций и расчётом стоимости. Add увеличивает количество на 1 кв. фут, Remove уменьшает на 1 и удаляет строку при переходе к нулю.
- Начальная сумма — **$13,100.00**. Доставка стоит $25 при сумме товаров до $500 включительно, выше $500 — бесплатно. Деньги рассчитываются в целых центах.
- Десктопный визуализатор 7×7: выбор плитки, размещение кликом, с клавиатуры и перетаскиванием. Корзина и раскладка независимы и хранятся в Redux.
- Проверка обязательных полей, email и карточных данных; четыре способа оплаты и локальное подтверждение заказа. Реальные платежи не выполняются, карточные данные не отправляются и не сохраняются.

## Запуск

Node.js 20.19+; рекомендуется Node.js 22 LTS.

```bash
npm install
npm run dev
```

Открыть http://localhost:3000. Для установки строго по lockfile используйте `npm ci`.

## Проверки и сборка

```bash
npm run lint
npm run typecheck
npm test
npm run build
npm start
```

Сборка создаёт статический сайт в `out/`. `npm start` показывает его на порту 3000.

Браузерные тесты Playwright:

```bash
npx playwright install chromium
npm run test:e2e
```

## Структура

- `src/store/` — независимые состояния корзины и раскладки.
- `src/lib/` — каталог, расчёт стоимости и валидация формы.
- `src/components/` — компоненты интерфейса; `tests/` — unit- и браузерные тесты.
- `tailwind.config.js` — цвета и шрифты.

Графика взята из макетов [задания Tile.Expert](https://gitlab.com/tile-expert-test-tasks/frontend). Исходники находятся в `design/`, скрипт извлечения декоративных фрагментов — `scripts/extract-assets.py` (Python + Pillow). Шрифт Oswald распространяется по [SIL Open Font License](public/fonts/OFL.txt).
